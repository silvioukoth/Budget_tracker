# Personal Budget & Expense Tracker

A responsive and interactive personal budget and expense tracking application built with HTML, CSS, Bootstrap, and JavaScript ES Modules.

## Features

* Add and manage personal expenses
* Organize expenses by category
* Calculate total expenses automatically
* Display expense information dynamically
* Responsive layout for desktop, tablet, and mobile devices
* Bootstrap grid, form, and button components
* Custom CSS styling for a personalized visual design
* JavaScript logic organized using ES Modules
* Separate `budget.js` module for reusable budget functions
* GitHub Pages deployment

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* JavaScript ES Modules
* Git
* GitHub
* GitHub Pages

## JavaScript Modules

The project uses ES Modules to keep the JavaScript code organized.

The `budget.js` file contains reusable budget functions including:

* `calculateTotal()`
* `renderExpenses()`

These functions are exported from `budget.js` and imported into `script.js`.

## Responsive Design

The application has been tested across different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

Bootstrap's responsive grid is combined with custom CSS media queries to provide a consistent experience across devices.
